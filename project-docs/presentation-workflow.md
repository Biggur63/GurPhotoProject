# Регламент создания презентаций для курса

## Общий принцип
- Для презентаций курса о композиции и восприятии единицей работы считается не раздел лекции, а отдельный тезис.
- Если в одном разделе лекции содержится несколько самостоятельных тезисов, каждому из них должен соответствовать отдельный слайд.
- Презентация строится не как краткий пересказ лекции, а как последовательное визуальное раскрытие всех её тезисов.

## Обязательный workflow
1. Прочитать лекцию, которую указал редактор.
2. Выделить все самостоятельные тезисы лекции.
3. Составить структуру презентации по принципу `1 тезис = 1 слайд`.
4. Для каждого тезиса подготовить отдельный блок в `slide-content-map.md`.
5. Найти в `content/blog` статьи, где уже поднимается тема данной лекции.
6. Отобрать из этих статей подходящие иллюстрации вместе с их `alt`-подписями.
7. Обязательно скопировать каждое выбранное изображение в папку `reference` конкретной презентации.
8. Остановиться до сборки `pptx` и передать редактору `slide-content-map.md` на чтение и правку.
9. Продолжать работу над презентацией только после подтверждения редактора.

## Что обязательно должно быть в slide-content-map.md
- Номер или порядок слайда.
- Заголовок слайда.
- Один точный тезис, которому посвящён слайд.
- Краткое раскрытие тезиса для слайда.
- Указание, из какой статьи блога взята опорная иллюстрация.
- Точный `alt`, который сопровождает выбранное изображение в статье.
- Пометка, какой файл изображения скопирован в `reference`.

## Правила работы с блогом
- Основной источник изображений для презентаций ─ папка `C:\Verstak\GurPhotoProject-publish\content\blog`.
- Блог считается живым и постоянно обновляемым источником.
- Перед каждой новой лекцией нужно заново просматривать релевантные статьи, а не полагаться на прошлый выбор.
- Если подходящая тема уже раскрыта в блоге, сначала использовать материалы оттуда и только потом рассматривать другие источники.
- При выборе изображения для презентации нужно переносить в работу не только сам файл, но и его смысловую подпись в `alt`.

## Правила создания слайдов
- Нельзя укрупнять несколько тезисов в один слайд только ради сокращения количества слайдов.
- Каждый слайд должен раскрывать один тезис ясно и отдельно.
- Структура презентации должна повторять логику тезисов лекции, а не формальную структуру её разделов.
- Если тезис слишком большой, его нужно делить на два слайда только тогда, когда внутри него действительно есть два отдельных смысловых шага.

## Точка остановки
- После подготовки `slide-content-map.md` и копирования изображений в `reference` AI обязан остановиться.
- До редакторской правки `slide-content-map.md` нельзя переходить к созданию `pptx`.
- Команда на сборку `pptx` считается отдельным следующим этапом, а не частью первичной подготовки презентации.
