# Continue workflow for article drafts

Этот сценарий нужен для связки `Codex -> файл статьи -> Continue -> черновик -> редактура`.

## Обязательная проверка правил

Перед любым действием по статье сначала нужно:

1. открыть `project-docs/ai-rules.md`
2. открыть `project-docs/preflight-checklist.md`
3. если тема относится к каналу `Фоторазговоры`, открыть `project-docs/content-plan-fotorazgovory-2026-05-to-2026-08.md`
4. если тема относится к каналу `Фоторазговоры`, открыть `project-docs/content-segment-fotorazgovory-2026-05-to-2026-08.md`
5. перечитать раздел правил, который относится к текущей задаче

Нельзя опираться только на память о регламенте, если правило уже зафиксировано в проекте.

## Что делает Codex

Когда вы пишете: `сделай публикацию по теме ...`, я могу:

1. Создать файл статьи в `content/blog/<slug>.md`.
2. Создать папку для будущих изображений в `assets/images/<slug>/`.
3. Оставить в файле маркеры для вставки черновика из Continue.
4. Подготовить для вас готовый промпт под конкретную тему.
5. Сохранить этот prompt отдельным файлом `project-docs/continue-prompt-<slug>.md`.

По умолчанию этот сценарий имеет приоритет:
- если пользователь просит подготовить статью или публикацию по теме, сначала нужно готовить заготовку файла, папку изображений и prompt для Continue
- не нужно сразу писать полный текст статьи, если пользователь отдельно не просит именно готовую статью без этапа Continue
- варианты названия статьи не нужно поручать Continue или бесплатной модели; заголовок для frontmatter и prompt подбирает Codex

## Команда `Статья - дата`

Когда редактор пишет команду в формате `Статья - дата`, нужно:

1. Открыть `project-docs/ai-rules.md`.
2. Открыть `project-docs/preflight-checklist.md`.
3. Открыть `project-docs/content-segment-fotorazgovory-2026-05-to-2026-08.md`.
4. Открыть `project-docs/content-plan-fotorazgovory-2026-05-to-2026-08.md`.
5. Найти в контент‑плане описание статьи по указанной дате публикации.
6. Считать все правила проекта, которые относятся к созданию промпта, стилю, структуре статьи, front matter и workflow Continue.
7. На основании описания темы, правила `Фоторазговоров` и общих правил проекта создать точный промпт для полного черновика статьи.
8. Дальше действовать по текущему workflow: создать файл статьи, папку изображений, маркеры для Continue, сохранить отдельный `project-docs/continue-prompt-<slug>.md` и передать готовый промпт редактору.

Если указанной даты нет в контент‑плане, тему не придумывать. Нужно сообщить, что дата не найдена, и попросить уточнить дату или обновить контент‑план.

## Что делаете вы

После этого от вас нужны только эти действия:

1. Откройте созданный `.md`-файл в VS Code.
2. Поставьте курсор между `<!-- CONTINUE_DRAFT_START -->` и `<!-- CONTINUE_DRAFT_END -->`.
3. Откройте панель Continue.
4. Выберите модель `Draft Free Router` или `Mistral Free`.
5. Возьмите шаблон из `project-docs/continue-draft-prompt-template.md` и замените placeholders на тему статьи, пункты из контент-плана и заметки.
6. Отправьте запрос в Continue.
7. В ответе Continue нажмите `Insert at cursor` или `Apply`, чтобы текст попал прямо в открытый файл.

## Что получите в итоге

- Черновик сразу окажется в нужном файле статьи.
- Папка для изображений уже будет создана.
- Отдельный `.md`-файл с prompt для Continue уже будет лежать в `project-docs/`.
- После этого можно возвращаться ко мне для доработки структуры, смысла, SEO и финальной редактуры.

## Как выглядит файл после создания

В новом `.md` уже будут:

- front matter
- служебный блок с темой, slug и путём к папке изображений
- маркеры `CONTINUE_DRAFT_START` / `CONTINUE_DRAFT_END`

Черновик нужно вставлять между этими маркерами.

## Ежедневный сценарий

1. Вы даёте тему из контент-плана или команду `Статья - дата`.
2. Если это команда `Статья - дата`, я нахожу тему по дате в `project-docs/content-plan-fotorazgovory-2026-05-to-2026-08.md`.
3. Если это тема `Фоторазговоров`, я сверяю её с правилом `project-docs/content-segment-fotorazgovory-2026-05-to-2026-08.md`.
4. Я создаю заготовку статьи.
5. Я даю вам готовый промпт для Continue под эту тему.
6. Вы вставляете его в Continue и нажимаете `Insert at cursor`.
7. Мы доводим статью до публикации.
